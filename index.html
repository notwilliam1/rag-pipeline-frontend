Pipeline Architecture

1

PDF Upload → S3

Frontend gets presigned URL → PUT directly to S3 bucket
2

S3 Event → Lambda (Processor)

S3 trigger fires → extract text, chunk (500 words / 100 overlap)
3

OpenAI Embeddings

text-embedding-3-small → 1536-dim vectors per chunk
4

Pinecone Upsert + DynamoDB

Vectors stored in Pinecone · metadata in DynamoDB
5

Query → Lambda (Streamer)

Embed query → top-5 Pinecone matches → stream answer via Poe RAG bot
